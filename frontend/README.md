# 今天吃什么？- 前端项目

这是"今天吃什么？"个人饮食助手的前端部分，基于Vue3 + Element Plus构建。

## 🚀 快速开始

### 开发环境启动
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 生产环境构建
```bash
# 构建生产版本
npm run build
```
